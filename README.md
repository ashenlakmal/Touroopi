# Touroopi - Travel & Explore 

**Touroopi** is a dynamic travel web application designed to help enthusiasts discover hidden gems and popular destinations. This project was developed as a part of the **Internet and Web Technologies (ICT 142-3)** course during the 1st Year, 2nd Semester at **Uva Wellassa University**.

---

##  Features

* **Diverse Travel Content:** Explore various travel categories including:
    * 🏖️ **Beachside** | 🌿 **Countryside** | 🧗 **Adventure**
    * 🏙️ **Urban** | 🏛️ **Ancient** | 🎉 **Festivals**
* **User Authentication:** Secure login and registration system using **PHP Sessions & Cookies**.
* **Hidden Places Contribution:** Registered users can share "Hidden Places" by submitting locations via an integrated **iFrame** map system.
* **Information Hub:** Detailed guides and information for every destination.

---

##  Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Backend:** PHP (Procedural)
* **Database:** MySQL (XAMPP / phpMyAdmin)
* **Authentication:** PHP Sessions & Cookies

---

##  Getting Started

1.  **Clone the repository:**
    ```bash
    [git clone https://github.com/ashenlakmal/Touroopi.git]
    ```
2.  **Database Setup:**
    * Start Apache and MySQL in XAMPP.
    * Create a database named `touroopi` in phpMyAdmin.
    * Import the SQL file from the `/database` folder.
3.  **Run Application:**
    * Place the folder in `htdocs`.
    * Visit `http://localhost/touroopi` in your browser.
